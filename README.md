# Sound Cue Support

Public issue tracker for support requests and bug reports for the Sound Cue iPhone app.

## How to submit an issue

You need a GitHub account to submit an issue.

1. [Search existing issues](https://github.com/octopussoftware-dev/sound-cue-interval-timer-support/issues), including closed issues, to see whether your question or problem has already been reported. If an issue already covers it, add any helpful details there.
2. [Open the support request form](https://github.com/octopussoftware-dev/sound-cue-interval-timer-support/issues/new?template=support.yml) and sign in to GitHub if prompted.
3. Give the issue a short, descriptive title, such as **[Support] Countdown sound does not play**.
4. Select the topic that best matches your request. Enter your **Sound Cue version and build** (found in Sound Cue → Settings → About) and your **iOS version** (found in the iPhone Settings app → General → About).
5. Under **What happened?**, include your iPhone model, what you expected, what actually happened, and the steps needed to reproduce the problem. For a general question, describe what you need help with. Attach screenshots if they help explain the issue.
6. Review the **Privacy confirmation**, check the box, and submit your issue.

**Issues and attachments are public.** Do not include personal, payment, health, or other sensitive information.

After submitting, return to your issue to check for replies and answer any follow-up questions in the comments.

## About this repository

The app source code is maintained separately and is not published in this repository.

Visit the [Sound Cue website](https://getsoundcue.app/) for information about the app.
